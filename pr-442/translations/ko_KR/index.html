Compute MMG's in-radius-ratio quality per triangle and apply a red->yellow->green material (red = poor, green = excellent). Requires an all-triangle mesh 삼각형마다 MMG 내접 반지름 비율 품질을 계산하고 빨강->노랑->초록 재질 적용 (빨강=낮음, 초록=우수). 모든 면이 삼각형인 메시가 필요합니다
How to map quality values onto the red->yellow->green ramp 품질 값을 빨강->노랑->초록 램프에 매핑하는 방법
Lower bound for the Custom colormap range (red end) 사용자 지정 컬러맵 범위의 하한 (빨강 끝)
Upper bound for the Custom colormap range (green end) 사용자 지정 컬러맵 범위의 상한 (초록 끝)
Map 0 -> red and 1 -> green. Absolute reading: a perfect equilateral triangle is solid green; anything below 0.5 is warning territory regardless of the rest of the mesh. 0은 빨강, 1은 초록에 매핑합니다. 절대 평가에서 완벽한 정삼각형은 초록이며, 0.5 미만이면 메시의 나머지 부분과 관계없이 주의가 필요합니다.
Stretch the ramp across the current mesh's min..max so the variation within this specific mesh is visible even when all triangles cluster near the same quality value. 모든 삼각형의 품질 값이 비슷해도 차이가 보이도록 현재 메시의 최솟값부터 최댓값까지 램프를 확장합니다.
Use the Custom Min / Custom Max sliders below as the ramp endpoints. Useful for comparing several meshes on the same fixed scale. 아래 사용자 지정 최솟값과 최댓값 슬라이더를 램프의 양 끝으로 사용합니다. 같은 고정 척도로 여러 메시를 비교할 때 유용합니다.
