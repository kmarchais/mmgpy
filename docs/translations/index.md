# Blender translation review

Each page compares every English message with one language. These pages are generated from `blender_mmgpy/translations.csv`.

Edit translations with the offline editor described in the [extension README](https://github.com/kmarchais/mmgpy/blob/main/blender_mmgpy/README.md#update-a-translation). Then regenerate these pages:

```bash
uv run --no-project python scripts/translation_review.py
```
